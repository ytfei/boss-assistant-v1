导出 PNG Chrome 扩展需要位图

Chrome 的 manifest.json 只接受 PNG，不接受 SVG。16 / 32 取自简化版，48 / 128 取自完整版。 仓库的 icons/ 已按这个规则生成并接好线；如需重新生成，点上方按钮下载后覆盖同名文件即可。 

"icons": {
  "16":  "icons/icon-16.png",
  "32":  "icons/icon-32.png",
  "48":  "icons/icon-48.png",
  "128": "icons/icon-128.png"
},
"action": {
  "default_icon": { "16": "icons/icon-16.png", "32": "icons/icon-32.png" }
}

本页可离线双击打开 —— 导出走 data URI + canvas，不依赖网络。
